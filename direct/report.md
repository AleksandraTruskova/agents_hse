# Отчёт: мини-трекер учебных задач (вариант B)

Дата: 2026-06-28

## Состав

- `index.html` — разметка: форма, сводка с прогресс-баром, фильтры, список.
- `styles.css` — мобильная вёрстка (max-width 480 px, `box-sizing: border-box`), читаемо на 390 px без горизонтального скролла.
- `app.mjs` — связка с DOM: добавление/удаление/переключение done, фильтры, ошибки рядом с полями (значения формы при ошибке сохраняются), localStorage с сообщением и работой в памяти при недоступном хранилище.
- `domain.mjs` — чистая логика без DOM и хранилищ: валидация, статистика, add/remove/toggle, фильтр.
- `tests/acceptance.test.mjs` — проверки T1–T5 на `node:test`.

## Реализованные правила

1. Операции реально меняют данные (add/remove/toggle возвращают новые коллекции).
2. Название после trim непустое; часы — число 0,5–24 с шагом 0,5; пустая строка часов — ошибка «пусто», а не ноль; ошибка показана рядом с полем, форма не очищается.
3. Прогресс = `round(100 × done / total)` по часам; при пустом списке — 0%, без NaN/Infinity.
4. Фильтр меняет только видимый список; итоги считаются по всем задачам.
5. Стартовый пример: 8 ч всего, 2 ч выполнено, 25%; «Практика» готова → 6/8 и 75%.
6. Интерфейс читаем на 390 px, поля и кнопки подписаны.

## Фактически проведённые проверки

Автоматизированные, `node --test tests/` (Node v26.13.1), 10/10 проходят:

- T1: исходный пример — 3 задачи, 8 ч, 2 ч, 25%.
- T2: «Практика» готова — 6/8, 75%, данные изменились.
- T3: фильтр «активные» — список из «Практики» и «Повторения», прогресс по всем задачам остаётся 25%.
- T4: отклонены пустое название, пробелы, пустые/отрицательные/нечисловые часы, 0.4/2.25/24.5/0 (границы 0.5 и 24 и шаг 0.5 приняты); некорректная задача не добавляется, валидная добавляется с trim.
- T5: после удаления всех задач — 0 ч, 0%, `Number.isFinite` истинно.
- `node --check app.mjs domain.mjs` — синтаксис модулей корректен.

## Предложенные ручные проверки интерфейса (браузер НЕ запускался)

- Открыть `index.html`: видны 3 задачи, сводка «Всего: 8 ч · Выполнено: 2 ч · Прогресс: 25%».
- Отметить «Практику» чекбоксом: сводка 6/8 и 75%, прогресс-бар заполнен на 75%.
- Включить «Активные»: в списке «Практика» и «Повторение», сводка не меняется; вернуть «Все».
- Отправить пустую форму: ошибки под обоими полями, введённые значения остались; отправить «   » и часы «-1»: ошибки, задача не появилась.
- Добавить «Эссе» 1.5 ч: задача в списке, сводка обновилась.
- Удалить все задачи: «0 ч · 0%», сообщение «Список пуст», форма и фильтры работают.
- Проверить ширину 390 px (DevTools): горизонтального скролла нет, элементы читаемы.
- Включить блокировку localStorage (DevTools): жёлтое сообщение о работе в памяти, трекер функционирует.
